# HXBot v1.7.3.1 · 服务器构建文档

**这份文档做什么：**从源码自己打出服务器的部署包（全量包 `hxbot-server-v1.7.3.1.zip`、从上一版升级用的更新包 `hxbot-server-update-v1.7.3.zip`）和其余交付件。平时由维护人员打好、随交付件一起给你，**直接用交付件里的包部署就行，不需要自己打**。需要自己核对或重新打包时，照这份文档做。

**打好之后怎么部署：**全新部署看《部署文档》；已经部署过的服务器升级看《上线操作手册》（按服务器 47.119.145.170 写好了每一步）。客户端（Mac、Windows、安卓、iPhone）的打包看《客户端构建》。

| 文档 | 写什么 |
| --- | --- |
| 服务器构建（本文） | 从源码打出服务器部署包 |
| 部署文档 | 在一台新服务器上从头部署，以及日常运维（用户管理、备份、停用） |
| 上线操作手册 | 每个版本怎么上线：上传客户端、升级服务器、检查（按这台服务器写好） |
| 客户端构建 | 打 Mac、Windows、安卓、iPhone 安装包（这一版在 GitHub 上打） |

---

## 1. 在哪里打包、要准备什么

在一台 Mac（Apple 芯片或 Intel 都可以）或 64 位 Linux 电脑上打，**不要在服务器上打**（服务器上没有也不需要这些工具）。

| 要准备的 | 怎么装 | 怎么确认 |
| --- | --- | --- |
| Xcode 命令行工具（只有 Mac 要） | `xcode-select --install` | `xcode-select -p` 显示一个路径 |
| Bun 1.4.2 | `curl -fsSL https://bun.com/install \| bash -s "bun-v1.4.2"`，装完重开终端 | `bun --version` 显示 `1.4.2` |
| Node.js 24 | 浏览器打开 https://nodejs.org/dist/latest-v24.x/ ，下载 `.pkg`（Mac）安装 | `node -v` 显示 `v24` 开头 |
| Python 3、git、zip、unzip | Mac 上随 Xcode 命令行工具装好；Linux 上 `apt-get install -y python3 git zip unzip` | `python3 --version`、`git --version`、`zip -v`、`unzip -v` |
| 磁盘 | 至少 15 GB 可用空间 | `df -h ~` |
| 网络 | 能访问 npm（下载依赖包，约 2 GB） | — |

## 2. 拿到源码

用交付件里的源码包，解压到**一个单独的新文件夹**（不要和打客户端用的源码目录共用：打服务器包会在源码目录里生成文件）：

```bash
mkdir -p ~/hx/1.7.3.1-server
cd ~/hx/1.7.3.1-server
unzip "/Volumes/US203/HX Web/2026-11-19/V1.7.3.1/hxbot-source-v1.7.3.1.zip"
cd hx-bot
grep -m1 '"version"' package.json        # 应显示 "version": "0.67.13",
```

下文的“源码目录”指 `~/hx/1.7.3.1-server/hx-bot`。

## 3. 安装依赖

```bash
cd ~/hx/1.7.3.1-server/hx-bot
bun install --frozen-lockfile
```

第一次要下载约 2 GB，十几分钟。最后没有 `error` 就好了。

## 4. 编译服务器

```bash
cd ~/hx/1.7.3.1-server/hx-bot
bash hx/scripts/build-server.sh
```

脚本依次做：核对改造（没有指向上游的地址）→ 核对每一项服务器设置都能从 `.env` 传到账号服务 → 编译账号服务（含网页版 `/app`）→ 复制数据库迁移 → 打包信令服务 → 复制中继服务配置 → 写入提交号和构建时间。约 5～10 分钟，最后一行是：

```
完成。上传 hx/server 目录到服务器 /opt/hxbot/server（见 hx/docs/部署文档.md）。
```

产物都在 `hx/server/` 里：

| 位置 | 是什么 |
| --- | --- |
| `hx/server/account/dist` | 账号服务（含网页版） |
| `hx/server/account/migrations` | 数据库迁移 |
| `hx/server/signal/signal.js` | 信令服务 |
| `hx/server/coturn/` | 中继服务配置 |
| `hx/server/BUILD_COMMIT`、`BUILD_TIME` | 提交号、构建时间（服务器上的 check.sh 用它核对运行中的程序是不是这个包） |

## 5. 打成交付包

更新包要和上一版的全量包比较，所以先把上一版的全量包放进 `dist-hx/`：

```bash
cd ~/hx/1.7.3.1-server/hx-bot
mkdir -p dist-hx
cp "/Volumes/US203/HX Web/2026-11-18/V1.7.3/hxbot-server-v1.7.3.zip" dist-hx/
bash hx/scripts/package-release.sh 1.7.3.1 1.7.3
```

脚本先跑十项检查（和维护人员交付前跑的一样，约 15～25 分钟，任何一项不通过就停下），再核对文档里写的包名就是这一版、文档的网页版是最新的，然后打包。最后列出：

| 文件（在 `dist-hx/` 里） | 是什么 |
| --- | --- |
| `hxbot-server-v1.7.3.1.zip` | 服务器全量包：全新部署、从任何旧版本升级都能用 |
| `hxbot-server-update-v1.7.3.1.zip` | 服务器更新包：只有 v1.7.3 以来变动的文件，只能从 v1.7.3 升级 |
| `latest.json` | 版本信息（服务器自动更新读它） |
| `SHA256SUMS` | 上面几个文件和源码包、补丁的 SHA-256 |
| `hxbot-source-v1.7.3.1.zip` | 源码包 |
| `hxbot-v1.7.3.1.patch` | 相对上游的全部改动 |
| `部署文档-v1.7.3.1.md/.html`、`上线操作手册-v1.7.3.1.md/.html`、`客户端构建-v1.7.3.1.md/.html`、`服务器构建-v1.7.3.1.md/.html` | 四份文档（`.html` 可以离线打开、打印） |
| `新功能说明-v1.7.3.1.md/.html` | 新功能与亮点（和官网 /whats-new/ 同一份原文：这一版在最前，含之前各版；`hx/docs/site/whats-new.zh.md` 开头的 `version:` 必须是这一版，否则打包停下） |
| `mac-signing-cert.sh`（v1.6.8 起另附，不由脚本生成） | 源码里 `hx/scripts/mac-signing-cert.sh` 的副本：在 Mac 上运行一次，生成 Mac 版的固定签名证书并写进打包仓库（《客户端构建》第 6.3 节第二部分）；2026-11-14 已经生成过，不要再运行 |

不写最后的 `1.7.3` 时，脚本取 `dist-hx/` 里版本最新的旧全量包做比较；`dist-hx/` 里没有旧全量包时只打全量包。

## 6. 核对

```bash
cd ~/hx/1.7.3.1-server/hx-bot/dist-hx
shasum -a 256 -c SHA256SUMS                       # 每一行都是 OK
unzip -p hxbot-server-v1.7.3.1.zip server/VERSION   # 1.7.3.1
grep '"commit"' latest.json                        # 和 unzip -p hxbot-server-v1.7.3.1.zip server/BUILD_COMMIT 显示的一样
```

自己打的包和交付件里的包内容相同，但里面的构建时间不同，所以 SHA-256 不会一样，这是正常的。部署时用哪一份都可以，同一次部署里全量包、更新包、`latest.json`、`SHA256SUMS` 要用同一次打出来的。

## 7. 出错了怎么办

| 提示 | 怎么办 |
| --- | --- |
| `需要 Node.js 24`、`bun: command not found` | 按第 1 节装好，重开终端 |
| `改造失败，以下位置在上游代码中找不到` | 源码不完整或被改过。按第 2 节重新解压到一个新的空文件夹 |
| `有检查不通过，见上面的输出。` | 十项检查有不通过的，把上面的输出发给维护人员 |
| `文档里的包名与本次版本 v1.7.3.1 不一致` | 打包命令里的版本号写错了，应是 `1.7.3.1` |
| `dist-hx/ 里没有上一版本的全量包（hxbot-server-v1.7.3.zip），这次只有全量包。` | 第 5 节的 `cp` 那一行没做或路径不对；要更新包就补上再打一次 |
| `ENOSPC` 或 `No space left on device` | 磁盘不够，清出 15 GB |
