# HXBot 研究版 · 使用说明（研究人员）

HXBot 是在自己电脑上运行一组 AI 智能体的工作台。每个智能体有独立的工作目录、对话和任务队列，可以互相发消息、传文件、操作内置浏览器。手机和网页版用来远程查看和对话。

## 1. 注册、登录并下载

1. 打开 https://bot.hxallai.com ，点“创建账号”：填写邮箱和手机号码，用发到邮箱和手机的验证码完成验证，再设置用户名、密码（8～32 个字符，字母、数字、符号都要有），填写职位和公司名称。注册完成后自动登录。一个邮箱、一个手机号码只能注册一个账号，用户名也不能和别人重复。
2. 以后用邮箱和密码登录。忘记密码时，在登录框下面点“忘记了密码？”，用发到邮箱的验证码设置新密码。
3. 在“下载客户端”里下载对应平台的安装包。
4. 服务器设了注册名单时，只有名单内的邮箱能注册，名单外的会提示“该邮箱不在研究版名单中”，请联系管理员把邮箱加入名单。

## 2. 安装桌面端（智能体运行在这里）

**Mac（Apple 芯片）**：打开 dmg，把 HXBot 拖进“应用程序”（要在“应用程序”里打开，以后才能在应用里更新）。第一次打开如提示“无法验证开发者”，点“完成”，到“系统设置 → 隐私与安全性”最下面点“仍要打开”（macOS 15 起右键“打开”已经不行）。从“下载”文件夹或磁盘映像里直接打开时，HXBot 会问要不要移到“应用程序”，点“移过去”。

**Windows**：运行 exe。如出现“Windows 已保护你的电脑”，点“更多信息 → 仍要运行”。

第一次启动时：

1. 阅读并确认权限说明。智能体拥有这台电脑上完整的文件、命令和网络权限，只运行你信任的任务，重要数据先备份。
2. 用同一个邮箱和密码登录。
3. 选择模型提供方。可以使用已有的 Codex（ChatGPT）、Claude、Gemini 等账号，或在“自定义提供方”里填写兼容 OpenAI 接口的模型服务地址和密钥（例如国内大模型平台的兼容接口，或本机的 Ollama、LM Studio）。
4. 新建第一个智能体，写清它的职责，开始对话。

智能体的工作目录在 `~/HXBot/Agents`（Windows 为 `%USERPROFILE%\HXBot\Agents`）。从旧版本升级的电脑继续使用原来的工作目录，智能体和文件都不用搬。

**直接打开应用和修改常用设置。**开了 Computer Use 的助手可以按名称直接打开这台电脑上的应用、系统设置的某一页、文件夹、文档和网址，也可以直接读或改 32 项常用设置（macOS 16 项：深色模式、音量、静音、程序坞的位置、大小、自动隐藏、放大等；Windows 16 项：深色模式、透明效果、任务栏对齐、时钟显示秒、主题色、接收通知、熄屏和睡眠时间等），不用截图、不动鼠标，所以很快。说法可以是中文、英文或拼音，例如“打开蓝牙设置”“把深色模式打开”“打开微信”“wangyiyun”。这些设置的直接修改已经在 macOS 和 Windows 的真机上逐项测过，助手直接改；只有 Windows 的屏幕亮度（测试机上没有可调亮度的屏幕）要先在这台电脑上运行一次自检（“设置 → Computer Use → 这台电脑上的应用和设置 → 运行自检”），通过后助手才直接修改，在那之前助手会打开设置页去改，慢一些，结果一样。其他设置，助手会先打开它所在的设置页，再用 Computer Use 在页面上改；隐私与安全、密码、登录项、开发者选项这类页面，助手只打开，由你自己改。助手打开了什么、改了什么设置，在“设置 → 授权与记录”里能看到。在“设置 → Computer Use → 这台电脑上的应用和设置”里可以重新建立目录（新装的应用找不到时用），也可以运行自检：它在这台电脑上实际试一遍，不会改变任何设置的值，结果存成“下载”文件夹里的一个文件。任务里不能用这项功能（屏幕留给助手自己的对话），定时任务里可以用。

**Mac 上的授权和装应用（v1.6.8 起）。**一步步操作应用只要“辅助功能”，截屏要“屏幕录制”。在“设置 → Computer Use”点“授予”：“辅助功能”的开关请你点一下（macOS 的规定），之后“屏幕录制”“App 管理”的开关由 HXBot 自己打开，你只输入密码或按指纹。每一版都用同一个签名，授权一次以后升级都有效（从 0.67.6 及以前升上来要再授权一次）。跟助手说“把下载好的 Firefox 装好”，HXBot 就把 .app、.zip、.dmg 里的应用装进“应用程序”，已经装过的先问你，旧版放进废纸篓；.pkg 交给系统的安装器。

**不打扰其他应用（v1.7.0 起）。**助手操作电脑时不再拖慢别的应用、不抢焦点：你切到别的应用后，助手不往那里打字，也不把窗口拉回前面，而是停下问你；授权页、远程控制的询问在你用别的应用时先发通知；一次操作结束松开修饰键，剪贴板保持你复制的内容；停止键 Ctrl+Alt+Esc 只在助手操作电脑时占用；更新下载限速 2 MB/s，远程桌面最多 10 Mbit/s；Windows 上停下助手时，它打开的有窗口的应用留下。自动选择模型在进行中的对话里保持原来的模型。

**应用命令和脚本（v1.6.9 起）。**开了 Computer Use 的助手可以直接让应用切到前台、隐藏、退出、把窗口放到左半边或右半边、最大化，点 Mac 应用菜单里的命令，读和改默认浏览器、邮件应用和按文件类型的默认应用；还能运行 AppleScript、JXA、快捷指令（Mac）和 PowerShell（Windows）来操作 Excel、Word 这类应用。都在 HXBot 自己里面做，不经过助手的命令行。退出时先正常退出，应用问要不要保存时由你在它的窗口里选，强制退出要你在对话里同意；删除、发送这类脚本先问你，要管理员权限的不运行。Mac 上第一次控制某个应用时，系统会问是否允许 HXBot 控制它，点“好”。一条路走不通，助手自动换下一条（直达 → 命令 → 控件 → 看图），并写明走的是哪条。

**自动选择模型和建议卡。**在助手设置里打开“自动选择模型”（在“模型”“备用模型”下面），助手每件新工作按内容和难度选模型（默认免费优先，难的工作才用订阅模型），对话里有一行小字写明用了哪个；一件事做不下来时回复“重做”换更强的模型。复杂的事助手先出一张建议卡（几个智能体、谁做什么、各用什么模型），点“开始”才动手。详见使用指南第 5 节。

**团队协作。**有两个以上角色的建议卡上，每个角色后面写着由谁来做（从你现有的助手里按专长选，没有合适的就新建一个成员）。点“开始”就组队：自动建一个协作房间（在频道里），带头的按步骤分派，成员之间用交接单交接、共用任务看板。谁把什么交给了谁、做完了几步，都以一行小字回到你和助手原来的对话；想插话、不做了或换人，直接跟助手说；做完后助手在原来的对话里告诉你结果。新建的成员在团队结束后自动收起（在隐藏的智能体里可以恢复）。团队的人数、时间、交接次数上限在助手设置的“建议卡”下面。详见使用指南第 5 节。

**连接 OpenCode 的全部服务商。**点模型面板的“+”（或“设置 → 服务商”），点“添加”，选“OpenCode 全部服务商”（服务商设置页底部也有“连接服务商”）：列出 OpenCode 能接的 200 多家服务商，最上面的 OpenCode Free 免费模型无需登录。每家按它支持的方式连接：网页登录、粘贴 API 密钥、或用电脑上已有的凭据（AWS、Google Cloud、Claude Code）。连上后 OpenCode 空闲时重启，这家的模型出现在助手的模型选择里，也进入“自动选择模型”的候选；点开已连接的服务商可以断开。凭据由 OpenCode 保存在你的电脑上，HXBot 不另存；只在桌面版上有。每个版本的新功能另见官网《新功能与亮点》：https://bot.hxallai.com/whats-new/ 。

**智能体的权限（最大权限）。**智能体默认是“最大权限”：读取任何位置的文件，在工作目录、共享文件夹、你添加的文件夹和临时文件夹里新建、修改、删除，在任何位置新建文件，运行命令，使用网站、截图、网络搜索和 Computer Use，都不用问你。下面这些事会先弹卡片请你确认：修改工作目录以外已有的文件、删除工作目录以外的东西、读写存放密钥和登录信息的位置（如 `~/.ssh`、钥匙串、浏览器资料）、以管理员身份运行命令（sudo）、在网页上填银行卡付款。用保密箱里保存的密码自动登录网站、删除保密箱条目不用问（v1.6.8 起）。卡片上选“允许一次”“始终允许”（以后所有智能体都不再问，可以在“设置 → 授权与记录”里删除）或“拒绝”；付款每次都要确认。发邮件、发消息、发布内容之前，智能体也会先在对话里问你。“设置 → 授权与记录”里还能看到智能体做过的值得留意的事。需要智能体什么都不问时，可以在智能体设置的“权限”里改成“完全访问”（要再确认一次），用完改回来。

## 3. 在网页和手机上使用

网页版和手机端连接的是你自己的桌面端，所以桌面端要开着并联网。

1. 在桌面端打开服务器设置，点“发布该服务器”，开启远程访问。
2. **网页版**：在门户点“进入网页版”，或直接打开 https://bot.hxallai.com/app ，会自动列出你发布的服务器。
3. **安卓手机**：用手机浏览器打开 https://bot.hxallai.com 登录并下载 APK 安装（需允许“安装未知应用”）。在桌面端“设置 → 手机连接 → 添加手机”扫码，或在手机上用同一邮箱登录。

## 4. 邀请同事加入你的服务器

在桌面端的服务器设置里创建邀请链接发给同事（链接形如 https://bot.hxallai.com/join?…）。同事注册并登录后打开链接即可加入，按你给的角色（成员或管理员）使用你电脑上的智能体。

## 5. 数据在哪里

| 数据 | 位置 |
| --- | --- |
| 对话、智能体、文件 | 运行桌面端的电脑上 |
| 账号、登录会话、你发布了哪些服务器 | 弘犀服务器 |
| 远程连接中传输的内容 | 点对点加密传输，不在弘犀服务器上保存 |
| 模型调用 | 由你选择的模型提供方处理，遵守该提供方的条款 |

## 6. 使用限制

- 研究版仅限非商业研究用途，不得用于任何商业目的（详见《许可与合规》）。
- 不要让智能体处理涉密、个人敏感信息或生产系统。
- 发现问题请记录：操作步骤、截图，以及桌面端“账号菜单 → 导出诊断信息”生成的文件，发给管理员。

## 7. 更新与注销账号

- **更新**：有新版本时客户端会自动下载。桌面端在后台下载好后弹出窗口介绍新功能，点“立即更新”或“以后再说”；大版本（例如 0.68.0）必须更新，窗口不能关，10 分钟内没人点会在空闲时自动安装；手机端整屏提示并自动打开新版本，你点“安装”即可。数据都会保留。桌面端 0.67.0、手机端 1.4.x 及以前的版本不能再登录，请在 https://bot.hxallai.com 登录后下载新版本安装。从 v1.6.1 及以前的版本升级上来时，所有设备要重新登录一次；之后的更新不用重新登录。
- **注销账号**：在“设置 → 个人资料”最下面点“注销账号…”，输入密码确认（手机端在“设置 → 个人资料 → 注销账号”）。账号立即删除、不能恢复，你电脑上的智能体、对话和文件不受影响。
