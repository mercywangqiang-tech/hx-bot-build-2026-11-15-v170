## 桌面端 0.67.9：HXBot 不打扰其他应用 {#desktop-0-67-9}

2026 年 11 月 15 日 · 桌面端和网页版 0.67.9 · 手机端 1.5.0（这次没有变化）

> **亮点**
> 1. {NEW} 不拖慢别的应用：高亮框不再一刻不停地读所有窗口，后台工作和助手运行的命令都让你的应用先用处理器。{on:桌面端}
> 2. 不抢焦点：你切到别的应用后，助手不往那里打字，也不把窗口拉回前面；授权页、远程控制的询问先发通知，点了才打开。{on:桌面端}
> 3. 快捷键、复制粘贴照常，不占满网络：操作结束松开修饰键，剪贴板保持你复制的内容；更新下载、远程桌面都限速。{on:桌面端}

### 不拖慢别的应用 {#desktop-0-67-9-fast}

![助手操作电脑时：在后台点、你切走了就不打字、结束时松开修饰键](/hx-portal/whats-new/computer-quiet.zh.jpg)

- **高亮框：**助手操作某个应用时，HXBot 在它的窗口外画一圈高亮框。原来每秒 30 次去问系统所有窗口的位置，每个应用都要不停回答，风扇响、别的应用变卡；现在每秒最多两次，只在助手最近 15 秒有过动作时才读，没动作时不读也不画。
- **Windows 上的鼠标：**灵动岛和停靠栏只在鼠标靠近它们时才接收鼠标的移动，平时不再挂着整台电脑的鼠标；高亮框完全不接鼠标。
- **处理器：**后台读应用目录用最低优先级；助手的进程和它运行的命令（编译、测试等）低于正常优先级，你自己的应用先用处理器。两分钟没人用的后台网页标签恢复节流。
- **大应用：**助手读一个窗口时最多读 1500 个控件、最多 3 秒，浏览器、Xcode、长文档这类大应用不会因为被读而卡住。

### 不抢焦点 {#desktop-0-67-9-focus}

- **按键只发给目标应用：**助手输入文字、按快捷键之前，先看最前面的是不是它在操作的应用。你切到了别的应用，按键就不发出去，也不把它的窗口拉回前面，而是停下来，在对话里请你回到那个应用后再继续。
- **先发通知：**助手要打开系统设置里的授权页、有人请求远程控制这台电脑时，你正在 HXBot 里就直接打开；你在用别的应用时只发一条通知，点了才打开。同一页短时间内只开一次。
- **更新以后：**自动更新装好、HXBot 重新打开时，你正在用别的应用的话，HXBot 在后面打开，不抢到前面（Mac）。

### 快捷键、复制粘贴照常，不占满网络 {#desktop-0-67-9-keys}

- **修饰键：**一次操作结束（包括被你停下）时，松开 Ctrl、Shift、Alt、Win（Mac：⌘ ⇧ ⌥ ⌃），别的应用的快捷键不会因为修饰键卡在“按下”而全乱。
- **停止键：**Ctrl+Alt+Esc（Mac：⌃⌥Esc）只在助手操作电脑时占用，平时还给其他应用。
- **剪贴板：**助手打字后，剪贴板里还是你原来复制的文字。
- **网络：**更新下载最多占用 2 MB/s，远程桌面的画面最多 10 Mbit/s，你的通话和网页留有余地。
- **不关你的应用：**Windows 上停下助手时，它打开的、有窗口的应用（例如记事本）留下，只停后台的进程。
- **自动选模型：**在已经进行中的对话里保持原来的模型和推理强度，服务商那边的上下文和缓存不丢；新对话、新任务，或者你点名换模型、要求重做时再重新选。

## 桌面端 0.67.8：助手直接用应用命令，走不通自动换路 {#desktop-0-67-8}

2026 年 11 月 14 日 · 桌面端和网页版 0.67.8 · 手机端 1.5.0（这次没有变化）

> **亮点**
> 1. 助手直接用应用命令：切到前台、隐藏、退出、摆窗口、点菜单命令、读写默认应用，都由 HXBot 自己做；退出先正常退出，强制退出先问你。{on:桌面端}
> 2. 助手能运行 AppleScript、JXA、快捷指令和 PowerShell，操作 Excel、Word 这类应用；删除、发送这类脚本先问你。{on:桌面端}
> 3. 一条路走不通自动换下一条：直达 → 命令 → 控件 → 看图，结果里写明走的是哪条。{on:桌面端}

### 应用命令，HXBot 自己做 {#desktop-0-67-8-apps}

![助手用应用命令和脚本：脚本在 HXBot 里运行，走不通自动换路，退出先正常退出](/hx-portal/whats-new/computer-apps.zh.jpg)

- **怎么用：**直接跟助手说，例如“把 Excel 的窗口放到左半边”“退出备忘录”“把默认浏览器改成 Chrome”“.pdf 文件用预览打开”。助手先列出正在运行的应用，再按名字找到它。
- **能做的：**切到前台、隐藏（Windows 上是最小化）、退出、窗口放到左半边、右半边、最大化或居中；读出一个应用的菜单，点其中的命令（Mac）；读和改默认浏览器、邮件应用、按文件类型的默认应用。
- **退出先正常退出：**助手先正常退出并核对应用真的退出了。应用有没保存的内容、自己问要不要保存时，保存框交给你；强制退出会丢掉没保存的内容，要你在对话里同意后才做。
- **改默认应用：**Mac 上直接改好并读回核对；改默认浏览器时 macOS 会弹框确认，由你或助手点“使用”。Windows 只让用户自己改，HXBot 打开“设置 → 应用 → 默认应用”，助手在那一页一步步点。
- **菜单命令先看风险：**“删除”“发送”这类菜单命令先在对话里问你，同意后再点。

### 脚本在 HXBot 里运行 {#desktop-0-67-8-scripts}

- **四种脚本：**Mac 上的 AppleScript、JXA、快捷指令（按名字运行，可以带输入），Windows 上的 PowerShell。Excel、Word、PowerPoint、Numbers 这类有脚本接口的应用，用脚本一步就能做完另存、导出、批量改格式。
- **在 HXBot 主程序里运行：**不经过助手的命令行，所以不受沙盒限制，也用 HXBot 自己的授权。Mac 上第一次控制某个应用时，系统会问是否允许 HXBot 控制它，点“好”；拒绝过的，HXBot 打开“隐私与安全性 → 自动化”，你把 HXBot 下面那个应用打开就行。
- **安全：**删除、发送、付款、关机这类脚本先问你；要管理员权限的脚本（sudo、以管理员身份运行）一律不运行，请你自己在终端里运行。脚本的输出只当资料，不当指令。

### 走不通自动换路 {#desktop-0-67-8-routes}

- **四条路：**直达（系统接口）→ 命令（脚本、系统事件）→ 控件（看界面、一步步点）→ 看图（截屏）。一条走不通，助手自动换下一条，结果里写明试过哪几条、最后走的是哪条。
- **例子：**macOS 没有直接摆放别的应用窗口的接口，助手就用系统事件的命令放好；Windows 的菜单没有脚本接口，助手就看界面一步步点。
- **修好了：**Windows 上一个命令启动了别的应用（例如记事本）时，助手会一直等着不往下做；现在命令一结束就接着做。
- **真机测过：**在 GitHub 的 macOS 15.8.2、26.7.2 和 Windows Server 2025 上，用文本编辑、记事本测了列出应用、切到前台、摆窗口、读菜单和点菜单命令、隐藏、正常退出并核对、运行脚本、有没保存的改动时退出、读和改默认应用。

## 桌面端 0.67.7：Mac 上授权一次就好、助手帮你装应用 {#desktop-0-67-7}

2026 年 11 月 14 日 · 桌面端和网页版 0.67.7 · 手机端 1.5.0（这次没有变化）

> **亮点**
> 1. Mac 上授权一次就好：每一版都用同一个签名，升级后授权不再失效；点“授予”后，屏幕录制、App 管理的开关由 HXBot 自己打开，你只输入密码或按指纹。{on:桌面端}
> 2. 助手能帮你装应用：下载好的 .app、.zip、.dmg 由 HXBot 装进“应用程序”文件夹；已经装过的先问你，旧版放进废纸篓。{on:桌面端}
> 3. 保密箱里保存的密码自动登录，不再拦着问，只有付款每次先问；最大权限下，OpenCode 在 Mac 上的命令不再被沙盒拦住。{on:桌面端}

### 授权一次就好，HXBot 自己点开关 {#desktop-0-67-7-grants}

![“设置 → Computer Use”的系统权限：屏幕录制只给截屏用，辅助功能由你点一下](/hx-portal/whats-new/computer-grants.zh.jpg)

- **升级后不再丢授权：**macOS 按应用的签名记授权。以前每一版的签名都不一样，升级后“屏幕录制”“辅助功能”就失效了，系统设置里却还显示打开。从这一版起每一版都用同一个签名，授权一次，以后升级都有效。
- **只要辅助功能就能操作应用：**一步步点按、输入只要“辅助功能”；“屏幕录制”只给截屏用。macOS 定期要求再确认屏幕录制时，一步步操作不受影响。
- **HXBot 自己点开关：**在“设置 → Computer Use”点“授予”，系统设置打开到那一页，HXBot 按下自己那一行的开关；macOS 要密码时，你输入密码或按指纹就好。“辅助功能”按 macOS 的规定要你自己点一下，打开后 HXBot 接着去开屏幕录制。助手操作应用时缺授权，也是同样的流程。
- **旧条目自动清掉：**某一项授权对这一版不生效时（开关显示打开，其实不算数），HXBot 先清掉自己的旧条目，再请你授权；只动 HXBot 自己的条目，不碰别的应用。
- **装在对的位置：**HXBot 不在“应用程序”文件夹里运行时（例如在“下载”或磁盘映像里），第一次打开会问你要不要移过去，点一下就移好并重新打开。
- **第一次装这一版：**macOS 第一次打开时会说“无法验证开发者”，到“系统设置 → 隐私与安全性”点“仍要打开”；再按上面的流程授权一次，以后升级不用再做。
- **全屏时关窗口不再黑屏：**以前在全屏（点绿色按钮）时点关闭按钮，HXBot 隐藏了，它的全屏空间却留下来，整块屏幕是黑的，要切到别的应用才恢复。现在先退出全屏再隐藏，点 Dock 图标就回来。
- **真机测过：**在 GitHub 的 macOS 15.8.2、26.7.2 真机上测过：同一张证书签出的两个版本签名身份相同；HXBot 经电脑操控驱动只按下自己那一行的开关，macOS 随即要密码；拿掉屏幕录制后一步步操作照样全部通过；清旧条目不要管理员密码，只清掉这个应用自己的。

![授权步骤窗口：HXBot 自己打开屏幕录制的开关，你只输密码或按指纹](/hx-portal/whats-new/grant-steps.zh.jpg)

### 助手帮你装应用 {#desktop-0-67-7-install}

![助手把下载好的 Claude 装进“应用程序”文件夹：先看签名和公证，替换前先问](/hx-portal/whats-new/computer-install.zh.jpg)

- **怎么用：**跟助手说“把下载好的 Claude 装好”。.app、.zip、.dmg 都可以，HXBot 自己解开、装进“应用程序”文件夹，再读回版本核对；.pkg 交给系统的安装器，要密码时由你自己输入。
- **先问再替换：**“应用程序”文件夹里已经有这个应用时，助手先在对话里问你；你同意后才替换，旧版放进废纸篓，可以找回。旧版正在运行时，请你先退出它。
- **安全：**装之前读出签名（开发者）和是否经过苹果公证，写在对话里；不去掉系统的隔离标记，第一次打开时 macOS 照常检查。
- **App 管理：**macOS 不让替换别的开发者的应用时，HXBot 打开“隐私与安全性 → App 管理”，自己点开 HXBot 的开关，你只输密码或按指纹。
- **真机测过：**在 GitHub 的 macOS 15.8.2、26.7.2 上，用一个测试应用测了新装、先问、替换（旧版进废纸篓、不留临时文件）和从磁盘映像装。

### 保密箱自动登录，只有付款先问 {#desktop-0-67-7-vault}

- **自动登录不再拦着问：**最大权限下，助手用保密箱里保存的密码登录网站（包括验证码）、删除保密箱条目，都不再弹卡片问你。
- **付款照样先问：**在网页上填银行卡付款，每次都先问你，只能“允许一次”。修改工作区以外的文件、以管理员身份运行命令、读写密钥文件夹，照旧先问。
- **OpenCode 不再被沙盒拦住：**自动选择模型常用的 OpenCode，在 Mac 上不再放进进程沙盒（每个操作仍先由 HXBot 按规则判定），所以 ps、brew、截屏、装应用不再“换到 OpenCode 就失败”。其他用沙盒的模型放开了 Homebrew、npm、pip 等包管理器的文件夹。
- **工具好找：**说“截图”“点击”“关闭应用”“安装应用”这类中文说法，助手也能找到对应的工具。

## 桌面端 0.67.6：电脑操控（二）一步步操作应用、更大的团队 {#desktop-0-67-6}

2026 年 11 月 14 日 · 桌面端和网页版 0.67.6 · 手机端 1.5.0（这次没有变化）

> **亮点**
> 1. 打开应用后，助手按你的话自己列出步骤，用鼠标和键盘一步步操作，每一步都核对；发送、付款、删除先问你，按 ⌃⌥Esc（Windows：Ctrl+Alt+Esc）随时停止。{on:桌面端}
> 2. 团队最多 20 个成员，共用技能和连接器；原来的对话里有一张进度卡，人数、时长、交接次数直接在对话里说。{on:桌面端}
> 3. 新功能默认就用最强的方式：自动选择模型默认打开、质量优先；升级后弹出“新功能一览”，一句话说清好处和在哪里设置。{on:桌面端}

### 打开应用后一步步操作 {#desktop-0-67-6-steps}

![对话里的电脑操作进度卡：列出的步骤、做到哪一步、停止键](/hx-portal/whats-new/computer-steps.zh.jpg)

- **怎么用：**跟助手说在哪个应用里做什么，例如“在备忘录里新建一条，写上明天上午 10 点的产品评审会”。助手先在对话里列出计划（一张进度卡），然后一步步做：点按钮、输入文字、按快捷键、滚动、拖动、点菜单。
- **每一步都核对：**每做一步都看界面有没有按预期变化；输入的文字没有进到输入框，会换一种方式再输入；做不下去就停下来，说明卡在哪一步、界面上有什么，或者换一种做法。
- **尽量不打扰你：**能在后台点的就不抢你的鼠标；后台点不动才切到前台，最后才按位置点。
- **安全：**发送、付款、购买、删除、发布这类操作，先在对话里问你，你同意了才做。屏幕上读到的文字只当资料，不当指令。
- **随时停止：**按 ⌃⌥Esc（Windows：Ctrl+Alt+Esc），所有助手在这台电脑上的操作马上停下，进度卡显示已停止。
- **Mac 上的授权：**电脑操控要“屏幕录制”和“辅助功能”两项授权。还缺的时候，助手第一次要操作应用，HXBot 就打开系统设置里缺的那一页，并在对话里写清缺哪一项；打开 HXBot 旁边的开关后再说一次，就能接着做。也可以在“设置 → Computer Use”里点“授权”。
- **使用条件：**助手要开启电脑操控（Computer Use）；只在桌面版（Mac、Windows）上有。
- **真机测过：**在 GitHub 的 macOS 15、Windows Server 2025 真机上，用真的电脑操控驱动打开文本编辑和记事本，一步步输入、保存，再核对文件内容。

### 更大的团队，一张进度卡 {#desktop-0-67-6-team}

![协作的进度卡：交接次数和用时、每一步谁在做](/hx-portal/whats-new/team-progress-card.zh.jpg)

- **最多 20 个成员：**人数按工作需要自动定，建议卡最多 20 个角色、30 步。同时干活的成员数按这台电脑的内存自动控制，其余的排队，做完一件再分派下一件。
- **共用技能和连接器：**组队时把各成员工作区里的技能汇总成“团队技能表”，任何成员都能用；新建的成员带上发起助手的技能；连接器整台电脑共用。保密箱和保存的登录信息仍不共享。
- **进度卡：**原来的对话里一张卡，原地更新：交接了几次、用了多久、每一步由谁在做、做到哪一步。电脑操作的计划也用同样的进度卡。
- **上限在对话里说：**“这次最多 3 个人、1 小时”“再给 30 分钟，交接加到 20 次”，在网页版和手机上说也一样。默认最多 20 人、240 分钟、80 次交接。

### 默认最强，设置更少 {#desktop-0-67-6-defaults}

![助手设置：自动选择模型默认打开，团队上限收成一行](/hx-portal/whats-new/team-summary.zh.jpg)

- **自动选择模型默认打开、质量优先：**每件工作用最合适、最强的模型；只有免费模型时用最强的免费模型。想省钱，在助手设置的“自动选择模型”里把“倾向”改成“免费优先”。你自己改过设置的助手保持原样。
- **设置更少：**助手设置里团队上限收成一行摘要，打开“调整上限”才看到细项。
- **新功能一览：**升级后第一次打开客户端，弹出这一版的新功能，每条一句话说好处、写明在哪里设置；看过不再弹，在“设置 → 关于”里可以再打开。
- **《隐私政策》1.5 版：**写明一步步操作、操作记录只在你的电脑上、停止键，以及自动选择模型默认打开以后，在助手设置里怎么关掉。

## 桌面端 0.67.5：协作（二）多智能体无缝协作 {#desktop-0-67-5}

2026 年 11 月 14 日 · 桌面端和网页版 0.67.5 · 手机端 1.5.0（这次没有变化）

> **亮点**
> 1. 说一句话就能组团队：在建议卡上点“开始”，HXBot 按专长挑选现有的智能体，缺的角色自动新建，开一个协作房间分工去做。{on:桌面端}
> 2. 成员之间用固定格式的交接单交接，共用一块任务看板：谁在做什么、卡在哪里，一目了然。{on:桌面端}
> 3. 进度和结果回到你原来的对话；想插话、叫停或换人，直接在对话里说。{on:桌面端}

### 说一句话，自动组队 {#desktop-0-67-5-team}

![建议卡写明每个角色由谁来做：现有的智能体，或者新建一个成员](/hx-portal/whats-new/team-card.zh.jpg)

- **怎么开始：**跟助手说要做的事。值得几个智能体分工时，助手先出建议卡；有两个以上角色的卡上，每个角色后面写着由谁来做。点“开始”就组队。
- **怎么选人：**按名字、头衔和介绍，从你现有的智能体里挑最合适的；你正在对话的这个助手不参加，它留在你身边。没有合适的角色就新建一个成员（用建议卡上给这个角色的模型，权限不超过发起的助手）。
- **协作房间：**自动建一个频道作为协作房间，带头的（定方案的那个角色）收到完整的简报：目标、分工、步骤、要用的应用、要你确认的地方、共用文件夹和上限。
- **新建的成员：**团队结束后自动收起（在隐藏的智能体里可以恢复）；想留下就跟助手说一声，或者在设置里改成“留下”。

### 交接单和任务看板 {#desktop-0-67-5-board}

- **交接单：**分派和转交时必须写清六项：目标、已完成、文件、未解决、下一步、不要碰，没有的写“无”。少写一项，HXBot 会退回去让它补齐，接手的成员不用再回头问。
- **任务看板：**每一步谁负责、做到哪、卡在哪，大家要用的事实和文件，都记在看板上；交接单里写的文件自动记上。
- **共用能力：**看板列出每个成员用的模型、能不能操作电脑；成员各自的技能和连接器照常可用，需要哪种能力就交给有这个能力的成员。几个成员同时打开应用或改设置时，排队一个一个来，不会打架。保密箱和保存的登录信息不共享。

### 在原来的对话里跟进 {#desktop-0-67-5-follow}

![对话里的协作进度：组队、交接、交回结果、完成](/hx-portal/whats-new/team-progress.zh.jpg)

- **看进度：**谁把什么交给了谁、做完了几步、哪里卡住了，都以一行小字出现在你原来的对话里；想看细节就打开协作房间。
- **插话、叫停、换人：**直接跟助手说（“海报用蓝色”“这件事不做了”“把写作者换成小张”），它会转给团队、停下团队或换人，换下的成员手上没做完的工作交给新成员。
- **结果：**带头的检查后交回最终结果，助手在原来的对话里告诉你结果和产出的文件。

### 团队的上限 {#desktop-0-67-5-limits}

![助手设置里的团队上限](/hx-portal/whats-new/team-settings.zh.jpg)

- 在助手设置的“建议卡”下面：团队成员最多几个（默认 5）、最长多久（默认 120 分钟）、最多交接几次（默认 20），新建的成员结束后收起还是留下。
- 到了时间或交接次数的上限，或者同一件工作失败了两次，团队就停下来，助手告诉你已经做了什么、还剩什么，问你接下来怎么做。

## 桌面端 0.67.4：连接 OpenCode 的全部服务商、协作（一） {#desktop-0-67-4}

2026 年 11 月 14 日 · 桌面端和网页版 0.67.4 · 手机端 1.5.0（这次没有变化）

> **亮点**

> 2. 助手按工作内容自动选模型：写作、编程、看图、定方案各用合适的模型，默认免费优先。{on:桌面端}
> 3. 复杂的事先出一张建议卡：几个智能体、谁做什么、各用什么模型，你点“开始”才动手。{on:桌面端}

### 连接 OpenCode 的全部服务商 {#desktop-0-67-4-opencode}

![OpenCode 全部服务商窗口：免费模型、已连接的服务商、网页登录或粘贴密钥](/hx-portal/whats-new/opencode-services.zh.jpg)

- **在哪里：**点模型面板的“+”（或“设置 → 服务商”），点“添加”，选“OpenCode 全部服务商”；服务商设置页底部也有“连接服务商”。
- **有哪些：**OpenCode 能接的 200 多家服务商，例如 OpenAI、Anthropic、DeepSeek、Kimi、智谱、通义、GitHub Copilot、OpenRouter，可以搜索。最上面的 OpenCode Free 免费模型无需登录、已经可用。
- **三种连法：**网页登录（像 ChatGPT 那样在浏览器里登录，完成后窗口自动显示“已连接”）；粘贴 API 密钥；使用电脑上已有的凭据（AWS、Google Cloud、Claude Code 等）。
- **连上以后：**这家的模型出现在助手的模型选择里（在 OpenCode 下面，按服务商分组），也进入“自动选择模型”的候选范围。随时可以断开。
- **安全：**凭据由 OpenCode 保存在你的电脑上（和在终端里运行 opencode auth login 一样），HXBot 不另存。这个功能只在桌面版上有。

### 按工作内容自动选模型 {#desktop-0-67-4-auto-model}

![助手设置里的“自动选择模型”](/hx-portal/whats-new/auto-model.zh.jpg)

![对话里写明每件工作用了哪个模型](/hx-portal/whats-new/auto-model-lines.zh.jpg)

- **打开：**在助手设置里打开“自动选择模型”（在“模型”“备用模型”下面）。
- **怎么选：**每接一件新工作，助手先判断是什么（闲聊、写作、小改代码、多文件编程、数据、看图、长资料、方案与推理、电脑操作）、有多难，再从你已登录的模型里选一个。对话里有一行小字写明用了哪个，例如“自动选模型 · 写作：由 GLM-5.3-Flash Free 来做。”
- **倾向：**默认“免费优先”，免费模型够用就用免费的；也可以选“均衡”或“质量优先”。
- **自己说了算：**在消息里点名（“改用 Claude Opus 5.5 重答”），这一条就用你点的模型；在“候选模型和最近的选择”里可以取消勾选不想用的模型，也能看到最近选了什么。
- **做不下来时：**对话里会问一句，回复“重做”就换更强的模型再做一遍。
- **拿不准时：**问一个便宜的小模型判断（可以改成“只用规则”）；都没把握就沿用现在的模型。

### 助手直接操作这台电脑 {#desktop-0-67-3-computer}

![对话里一句话打开应用、直接改设置](/hx-portal/whats-new/computer-open.zh.jpg)

![设置 → Computer Use：这台电脑的目录和自检](/hx-portal/whats-new/computer-catalog.zh.jpg)

- **按名字打开：**应用、系统设置页、文件夹、文档、网址都可以，例如“打开网易云音乐”“打开蓝牙设置”。中文名用全拼或首字母也行（“wangyiyun”“wyyyy”都能找到网易云音乐）。
- **直接改设置：**macOS 16 项（深色模式、音量、静音、程序坞的自动隐藏和大小、菜单栏自动隐藏等），Windows 16 项（深色模式、透明效果、任务栏对齐、时钟显示秒、通知、游戏模式、熄屏和睡眠时间等）。改完会再读一遍，确认改对了；对不上就自动改回原值。
- **这台电脑的目录：**HXBot 自动记下装了哪些应用、有哪些系统设置页（macOS 40 页，Windows 57 页），助手查找时不用等。装了新应用，可以在“设置 → Computer Use”里“重新建立目录”。
- **自检：**“设置 → Computer Use”里可以一键检查每项设置能不能读、能不能改；自检不会改变任何设置的值。Windows 的屏幕亮度要先通过一次自检，助手才会直接改。
- **安全：**隐私、密码、登录项这类安全相关的页面，助手只打开，不替你改；可以直接运行的文件（如 .exe、.sh）不会被打开。助手打开了什么、改了什么，都记在“设置 → 授权与记录”里。
- **使用条件：**先为助手开启 Computer Use。手机端和网页版没有这个功能。
- **测得充分：**在 macOS 15、macOS 26、Windows Server 2025、Windows Server 2022、Windows 11 ARM 五种真机上自动测了五轮，每项设置都真的改过再改回，最后一轮 0 失败。
