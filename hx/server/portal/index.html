服务器邀请链接

邀请同事加入你的服务器

“服务器”就是运行 HXBot 桌面端的那台电脑。邀请链接由服务器所有者在桌面端创建，每个链接都不同，形如 https://bot.hxallai.com/join?api=…&server=…&fingerprint=…&invite=…，里面带着这台服务器的编号、身份指纹和一次性凭证，所以无法提前给出一个通用链接。

所有者：创建邀请链接

  1. 在 Mac 或 Windows 上打开 HXBot 桌面端，用邮箱和密码登录。
  2. 在左侧服务器栏右键（或点“…”）当前服务器，选“服务器设置”，打开“成员”。
  3. 打开“发布该服务器”，显示“可在公网访问，仅受邀者可以登录”。
  4. 点“邀请成员”，邀请方式选“邀请链接”，选好角色（成员或管理员），点“创建链接”，再点“复制链接”，发给同事；同事用手机时也可以点“显示邀请二维码”让对方扫码。

一次性链接 24 小时后过期，用过一次即失效；“永久链接”不会过期、可多次使用，任何拿到它的人都能加入，只发给信任的人，不用时在“待处理的邀请”里撤销。研究版没有配置发信，请用“邀请链接”，不要选“邮箱”。

同事：用邀请加入

  1. 先在本页登录（还没有账号请先注册）。
  2. 打开网页版 https://bot.hxallai.com/app，点“用邀请加入”；或在自己的桌面端、安卓端点“添加服务器”。
  3. 粘贴收到的链接，点“查看邀请”，核对服务器名称后确认加入。

也可以直接在浏览器里打开收到的邀请链接，页面会引导你在 HXBot 中打开它。服务器所在的电脑需要开机并运行 HXBot，加入后才能对话。
