HXBot 是在你自己的电脑上运行一组 AI 智能体（在客户端中称为“助手”）的工作台。每个助手有自己的职责、工作区、对话和任务队列，可以互相发消息、传文件、操作内置浏览器；网页版和手机端用来远程查看进度、继续对话。本指南从注册账号讲到邀请同事，按顺序读一遍即可上手。

五分钟上手

  1. 在 https://bot.hxallai.com 点“创建账号”，用邮箱注册并设置密码（第 2 节）。
  2. 登录后下载 Mac 或 Windows 桌面端并安装（第 3 节）。
  3. 打开桌面端，用同一个邮箱和密码登录，选择“设置这台电脑”（第 4 节）。
  4. 选择“使用免费模型”或“使用我的 AI 订阅”，然后创建第一个助手（第 4、5 节）。
  5. 需要在手机、网页上使用或邀请同事时，发布服务器并创建邀请链接（第 6、7 节）。

1. HXBot 由哪些部分组成#

部分作用在哪里获取
桌面端（Mac、Windows）运行助手。装了桌面端的电脑就是你的“服务器”，助手、对话和文件都保存在这台电脑上登录门户后在下载中心下载
网页版在浏览器中远程使用你有权访问的服务器https://bot.hxallai.com/app
安卓端、iOS 端在手机上查看进度、和助手对话、接收提醒安卓：下载中心的 APK；iOS：下载中心的安装入口（TestFlight 或直接安装）
弘犀服务器负责账号、登录、服务器目录、邀请、建立加密连接和中继由弘犀智能运营，不保存你的对话和文件

几个常用说法：

  • 服务器（主机）：运行桌面端的那台电脑。“发布”服务器后，受邀的人可以从网页、手机或他们自己的桌面端连接进来。
  • 助手：一个有固定职责的 AI 智能体，例如“行程规划师”“收件箱助手”。
  • 频道：把多个助手（和成员）放在一起协作的对话。
  • 服务商：助手使用的 AI 模型来源，例如 ChatGPT、Claude、Grok、免费模型或兼容 OpenAI 接口的端点。

2. 注册账号并登录#

每个人用自己的账号使用 HXBot：用邮箱注册，设置自己的密码，所有客户端都用邮箱 + 密码登录。

注册账号：

  1. 打开 https://bot.hxallai.com ，在登录框里点“创建账号”。
  2. 填写邮箱和手机号码，点“下一步”。页面提示验证码已发送时，到邮箱和手机上查看（6 位数字，10 分钟内有效）。
  3. 填写验证码、用户名、密码（8～32 个字符，字母、数字、符号都要有）、职位和公司名称，点“完成注册”。注册完成后自动登录。

登录框下方显示“微信”“支付宝”等按钮时，也可以用这些账号登录：第一次使用时按页面提示注册新账号，或输入邮箱和密码绑定已有的账号；以后点按钮即可登录。

在门户登录：

  1. 打开 https://bot.hxallai.com 。
  2. 输入邮箱和密码，点“登录”。
  3. 登录后可以下载客户端、进入网页版。右上角“退出登录”可以退出。

忘记密码：在登录框下方点“忘记了密码？”，输入注册邮箱，用邮件里的验证码设置新密码。设置后，其他设备上的登录会全部退出，要用新密码重新登录。收不到邮件时，用注册邮箱发邮件到 bot@hxallai.com。

注意：

  • 注册和找回密码都在门户页完成。桌面端、手机端和网页版的登录界面只需要输入邮箱和密码。
  • 各个客户端都用同一个账号登录，登录后会看到同一组服务器。
  • 密码只供你本人使用，不要告诉别人，也不要与其他网站共用同一个密码。我们只保存密码的加盐哈希，任何人都看不到你的密码。
  • 页面提示“尝试太频繁”或“操作太频繁”时，请过几分钟（最长约 15 分钟）再试。两次获取验证码至少要隔 1 分钟，同一个手机号每天最多能收到 10 条验证码短信，超过后第二天再试。提示“密码输错次数太多”或“停留时间过长”时，点“重新开始”再输入一次。
  • 短信验证码只支持中国大陆手机号。收不到验证码、或使用其他国家和地区的手机号时，请发邮件到 bot@hxallai.com。
  • 一个邮箱、一个手机号码只能注册一个账号，用户名也不能和别人重复。提示“这个手机号已经注册了账号”时，请用那个账号登录（忘记了密码就点“忘记了密码？”）。
  • 以前用共用登录口令登录过的用户：请用原来的邮箱“创建账号”并设置自己的密码，原来的服务器和成员关系都会保留。

3. 下载与安装#

登录门户后，在“客户端下载”中选择你的设备。

设备系统要求安装说明
MacApple 芯片（M1 及以上），macOS 13 或更新打开 dmg，把 HXBot 拖进“应用程序”
WindowsWindows 10 / 11，64 位运行 exe 安装程序
AndroidAndroid 7.0 或更新用手机浏览器打开门户、登录后下载 APK 安装
iPhone / iPadiOS 16.4 或更新用 iPhone 或 iPad 打开门户、登录后看 iPhone / iPad 卡片上的按钮：“在 TestFlight 中安装”或“安装”，见下面的说明

iPhone 和 iPad 的安装方式以下载中心卡片上显示的为准：

  • 卡片上是“在 TestFlight 中安装”：先在 App Store 安装苹果的“TestFlight”，再点这个按钮，在 TestFlight 里点“安装”。任何 iPhone、iPad 都可以装，以后的新版本也在 TestFlight 里更新。
  • 卡片上是“安装”：这是直接安装，只适用于已经登记的设备。请先把设备标识（UDID）发到 bot@hxallai.com 登记；登记后用 Safari 打开门户、登录后点“安装”，回到主屏幕等图标装好。iOS 16 及以上第一次打开前，要在“设置 → 隐私与安全性 → 开发者模式”里打开开发者模式并重启设备。微信等应用里的内置浏览器不能安装，请用 Safari。
  • 卡片上是“即将推出”：iOS 版还没有发布。

Mac 和 Windows 的研究版安装包没有做代码签名，系统第一次可能会拦截：

  • Mac 提示“无法验证开发者”或“已损坏”：在“访达 → 应用程序”中右键点“HXBot”，选“打开”；仍无法打开时，在“终端”中运行下面的命令后再打开。
xattr -dr com.apple.quarantine "/Applications/HXBot.app"
  • Windows 出现“Windows 已保护你的电脑”：点“更多信息 → 仍要运行”。
  • Android 提示禁止安装：按提示允许浏览器“安装未知应用”。如果之前装过签名不同的版本，请先卸载旧版本。

更新：登录后客户端会自动检查新版本。更新不强制，大版本也一样；桌面端打开时自动更新。助手和对话不会因为更新而丢失（仍建议定期备份）。

  • 桌面端（0.67.10 起）：打开 HXBot 时找到的新版本，在后台下载、装好，等助手都空闲时自动重启进入新版，不用点；重启前会提示“HXBot 正在安装更新”，想等一会儿可以点“取消更新”，正在进行的工作先做完。用着用着才找到的新版本，下次打开时再装。0.67.9 及更早的版本仍按原来的方式：新版本下载好后弹出窗口，点“立即更新”或“以后再说”。管理员要求某个版本必须更新时，“更新 HXBot”挡住窗口、不能关，点“立即更新”即可，还在下载时点了，下载完自动重启安装。Windows 只下载有变化的部分；Mac 下载新版本，重启时替换。Mac 版要先拖进“应用程序”文件夹再打开（直接在 dmg 或“下载”文件夹里打开的不能在应用里更新）。更新失败时可以点“重试”，或点“打开下载页面”手动下载安装。
  • 手机端：整屏提示“更新 HXBot”，并自动打开新版本：安卓下载新的安装包，下载完成后打开、按提示安装；iPhone 在弹出的窗口里点“安装”。系统规定最后一步“安装”要你自己点。
  • 旧版本：桌面端 0.67.0、手机端 1.4.x 及更早的版本没有应用内更新，不能再登录，也不会出现“立即更新”。请用浏览器打开 https://bot.hxallai.com 登录，在下载中心下载新版本，直接安装覆盖旧版本。
  • 升级到这一版时，所有设备都要重新登录一次。
  • 当前版本号在桌面端“设置 → 关于”中查看。

4. 首次启动桌面端#

  1. 登录。输入邮箱和密码（还没有账号时先到 https://bot.hxallai.com 注册）。登录页底部写着“继续即表示你接受服务条款并已阅读隐私政策”，点击可以查看全文。
  2. “帮助改进 HXBot”。研究版不收集使用统计和错误报告，无论你如何选择，客户端都不会发送这些数据。
  3. “HXBot 将在哪里运行？”
    • 选“设置这台电脑”：助手、对话和文件都留在这台电脑上。大多数研究人员选这一项。
    • 选“连接到主机”：使用别人运行的服务器。粘贴对方发来的 https://bot.hxallai.com/join 邀请链接，点“查看邀请”，核对后点“连接到主机”。
  4. 选择 AI（“组建你的 AI 团队。”）。
    • “使用免费模型”：无需 AI 订阅。HXBot 会自动下载第三方开源工具 OpenCode，并使用它提供的免费模型。免费模型的可用性、地区限制和条款由其提供方决定。
    • “使用我的 AI 订阅”：使用你已有的 ChatGPT、Claude 或 Grok 等账号。在“连接你的套餐”中登录一次，助手即可使用你的套餐。
  5. “HXBot 可能会控制你的电脑”。这一步说明 Computer Use（操控屏幕、键盘和鼠标）需要的系统权限。助手默认是“最大权限”：大多数事情直接做，修改工作区以外已有的文件、删除工作区以外的东西、以管理员身份运行命令、用保存的密码登录、付款这几类事先问你（见第 5 节）。请只运行你信任的任务，并做好备份。
  6. “创建第一个助手”。见第 5 节。

使用其他模型：在服务器栏右键你的服务器 → “服务器设置” → “服务商”，可以连接更多服务商；“添加服务商或助手”中的“添加自定义服务商”支持任何兼容 OpenAI 接口的端点（例如国内大模型平台的兼容接口），“在这台电脑上发现”会列出本机运行的模型服务（例如 Ollama、LM Studio）。使用第三方模型服务时，请遵守其条款和地区限制。

5. 助手与对话#

创建助手：点侧栏的“新建助手”，填写：

  • 名称；
  • 这个助手要帮你做什么？——写清它的职责、输出要求和边界，例如“每天整理行业新闻，按主题分类，附原文链接”；
  • 助手模型——选择服务商和模型；
  • 也可以从“推荐”中挑一个模板，再按需修改。

然后点“创建助手”。

对话：在助手的对话框中输入任务，可以附加文件、使用语音输入。助手会在自己的工作区里工作，过程和结果都显示在对话中。需要另起一个话题时，用助手菜单中的“新话题”。

多个助手协作：用“新建频道”把几个助手放进同一个对话，让它们分工完成任务；用“新建文件夹”整理侧栏。

自动选择模型：在助手设置的“自动选择模型”里（在“模型”“备用模型”下面），桌面端 0.67.6 起默认打开（你改过设置的助手保持原样）。助手每接一件新工作，先判断是什么（闲聊、写作、编程、数据、看图、长资料、方案、操作电脑）、有多难，再从你已登录的模型里选一个；对话里会出现一行小字，例如“自动选模型 · 写作：由 GLM-5.3-Flash Free 来做。”。

  • 倾向：默认“质量优先”，每件工作用最合适、最强的模型；只有免费模型时用最强的免费模型。想省钱就选“免费优先”（免费模型够用就用免费的，难的工作才用订阅模型），也可以选“均衡”。
  • 点名模型：在消息里写“改用 Claude Opus 5.5 重答”，这一条就用它。
  • 做不下来时：一轮失败或助手说做不了，对话里会问一句；回复“重做”就换更强的模型再做一遍。
  • 候选模型：在“候选模型和最近的选择”里可以取消勾选不想用的模型，也能看到最近几次选了什么。
  • 判断方式：默认“规则，拿不准时问小模型”：拿不准的那条消息（不含附件内容）会发给一个便宜的模型判断类型；选“只用规则”就不发。规则和小模型都没把握时，助手沿用现在的模型。
  • 你在模型下拉里手动选了一个模型，“自动选择模型”就会关掉。频道里的工作这一版不换模型。
  • 桌面端 0.67.9 起，已经在进行中的对话里助手保持原来的模型和推理强度（换模型会让服务商那边从头开始，上下文和缓存都没了）；新对话、新任务，或者你点名换模型、说“重做”，或者发来当前模型看不了的图片、放不下的长资料时，才重新选。打招呼、道谢这类消息不再另外请小模型判断。

连接 OpenCode 的全部服务商：点模型面板的“+”（或“设置 → 服务商”），点“添加”，选“OpenCode 全部服务商”（服务商设置页底部也有“连接服务商”）。窗口里是 OpenCode 能接的 200 多家服务商，可以搜索；最上面的 OpenCode Free 免费模型无需登录、已经可用。

  • 网页登录：像 ChatGPT、GitHub Copilot 这类，点“网页登录：…”，在打开的浏览器页面里登录，回到窗口会自动显示“已连接”；要粘贴代码的，把登录页显示的代码填进去。
  • API 密钥：点“粘贴 API 密钥”，把服务商给你的密钥粘进去，点“连接”。
  • 本机凭据：AWS、Google Cloud、Claude Code 这类，用你电脑上已经登录好的凭据。
  • 连上后，OpenCode 空闲时会自动重启，然后这家的模型出现在助手的模型选择里（在 OpenCode 下面，按服务商分组），也会进入“自动选择模型”的候选范围。点开已连接的服务商可以“断开”。
  • 凭据由 OpenCode 保存在你的电脑上（和在终端里运行 opencode auth login 一样），HXBot 不另存。这个功能只在桌面版上有。

建议卡：一件事值得几个助手分工，或者需要“做的”和“查的”分开时，助手会先出一张建议卡：建议几个智能体、每个角色做什么、各用什么模型（是否免费）、分几步、要用哪些应用、哪几步要你确认。点“开始”才动手；“改一改”告诉它要怎么改；“就用一个智能体”让它一个人做。在助手设置的“建议卡”里可以设成“每次长任务都出”或“不出”。

团队协作：有两个以上角色的建议卡，每个角色后面写着由谁来做：从你现有的助手里按专长选，没有合适的就新建一个成员。点“开始”后自动组队，建一个协作房间（在频道里），带头的按步骤分派：

  • 交接单：每次分派和转交都要写清目标、已完成、文件、未解决、下一步、不要碰，接手的成员不用再回头问。
  • 任务看板：每一步谁负责、做到哪、卡在哪，大家要用的事实和文件都记在看板上。
  • 在原来的对话里跟进：你和助手的对话里有一张进度卡，原地更新：交接了几次、用了多久、每一步由谁在做、做到哪一步。想插话、不做了或换人，直接跟助手说。做完后，助手在这里告诉你结果和产出的文件。
  • 共用技能和连接器：组队时，各成员工作区里的技能汇总成“团队技能表”，任何成员都能用；新建的成员带上发起助手的技能；连接器整台电脑共用。保密箱和保存的登录信息不共享。
  • 上限：团队不设人数、时长、交接次数上限：人数按工作定，分派一律接收、进看板排队；同时干活的成员数由这台电脑按可用内存、电池和温度自动安排，其余的排队，你发的消息先做。想给某一次定上限，直接跟助手说，例如“这次最多 3 个人、1 小时、最多花 20 元”或“这次不用问我，跑完为止”，在网页版和手机上说也一样，只对这一个团队有效。助手设置的“建议卡”下面有一行“团队：人数按工作定；同时干活由电脑安排（现在 n 个）”，下面可以选为团队新建的成员在团队结束后收起还是留下。团队卡住时会暂停：实际干活 30 分钟没有进展、同一件工作来回转手、越分越散（第一次只提醒带头的）、干满 24 小时、花费提醒连着 10 次没人回应；暂停时不开新的工作，正在做的做完，问你继续、收尾还是停。同一件工作失败两次，团队停下。

左侧导航：“助手”是对话主界面；“日程”“任务”“工作流”用来安排定时任务和自动化流程；“用量”查看各服务商的使用情况；“资料库”查看和管理文件；“设置”见第 8 节。

权限：最大权限。每个助手默认“最大权限”（以前的助手升级到这一版时也改成了最大权限，包括原来是“完全访问”的），在助手设置的“权限”里可以查看和修改：

  • 不用问：读取任何位置的文件；在自己的工作区、共享文件夹、你添加的文件夹和临时文件夹里新建、修改、删除；在任何位置新建文件；运行命令；打开和操作网站；截图；网络搜索；Computer Use（操控屏幕、键盘和鼠标）。
  • 先问你：修改工作区以外已经有的文件；删除工作区以外的文件；读取或写入存放密钥和登录信息的位置（例如 ~/.ssh、钥匙串、浏览器的资料文件夹、HXBot 自己的数据和保密箱）；以管理员身份运行命令（sudo 等）；看不出要删除什么的命令；在网页上填银行卡付款。
  • 不用问（v1.6.8 起）：用保密箱里保存的密码自动登录网站（包括验证码），删除保密箱里的条目。
  • 确认卡片：助手会在对话里弹出卡片，写明为什么、要做什么、对哪些文件、命令或网站做。选“允许一次”只这一次有效（每个对象用一次，任务结束后没用完的也收回）；选“始终允许”以后所有助手做同样的事都不再问（文件按所在的文件夹记住）；选“拒绝”或跳过就不做。也可以在卡片里写附加条件（例如“只改第 3 页”），原话转给助手。付款没有“始终允许”，每次都要确认。
  • 对话里先问：发邮件、发消息、发布内容、替你接受条款之前，以及用 Computer Use 输入密码或付款之前，助手会先在对话里问你（这些 HXBot 看不到，靠助手遵守）。
  • 规则和记录：“始终允许”的规则在“设置 → 授权与记录”里可以查看和删除；那里也记录助手做过的值得留意的事（工作区以外的读取和修改、删除、命令、截图、网络搜索、登录、付款，以及你的每次确认），只保存在这台电脑上，保留最近 2000 条，可以清空。
  • 谁能同意：只有服务器所有者能允许，团队成员只能拒绝。
  • 完全访问：助手什么都不问，包括删除文件、以管理员身份运行命令和付款。要在“权限”里手动选择，并确认两次；任务做完后建议改回最大权限。
  • Computer Use：在“设置 → Computer Use”中开启。macOS 上一步步操作只要“辅助功能”，截屏要“屏幕录制”。点“授予”：系统设置打开到那一页，“辅助功能”的开关请你点一下（macOS 的规定），之后“屏幕录制”的开关由 HXBot 自己打开，macOS 要密码时你输入密码或按指纹即可。某一项显示打开却不算数时，HXBot 先清掉自己的旧条目再请你授权。v1.6.8 起每一版都用同一个签名，授权一次，以后升级都有效（从更早的版本升上来要再授权一次）。还没授权时，助手第一次要操作应用，HXBot 打开系统设置里缺的那一页（v1.7.0 起：你正在用别的应用时只发一条通知，点了才打开），并在对话里说清缺哪一项；授权后再说一次就能接着做。HXBot 不在“应用程序”文件夹里运行时，第一次打开会问你要不要移过去。
  • 装应用（Mac）：跟助手说“把下载好的 Firefox 装好”。.app、.zip、.dmg 里的应用由 HXBot 装进“应用程序”文件夹，装之前在对话里写出它的开发者和是否经过苹果公证；已经装过的先问你，同意后才替换，旧版放进废纸篓（名字是“应用名 旧版本号”，可以放回）；正在运行的请你先退出。.pkg 交给系统的安装器，密码由你自己输入。macOS 不让替换时，HXBot 打开“App 管理”那一页并自己打开开关，你输入密码或按指纹。
  • 应用命令和脚本（v1.6.9 起）：助手可以直接让应用切到前台、隐藏、退出、把窗口放到左半边或右半边、最大化，读出 Mac 应用的菜单并点其中的命令，读和改默认浏览器、邮件应用和按文件类型的默认应用，例如“退出备忘录”“把默认浏览器改成 Chrome”。退出时先正常退出并核对；应用问要不要保存时由你在它的窗口里选，强制退出要你在对话里同意。助手还能运行 AppleScript、JXA、快捷指令（Mac）和 PowerShell（Windows），用来操作 Excel、Word 这类应用；删除、发送这类脚本先问你，要管理员权限的不运行。这些都在 HXBot 主程序里做，不经过助手的命令行。Mac 上第一次控制某个应用时，系统会问是否允许 HXBot 控制它，点“好”；拒绝过的到“系统设置 → 隐私与安全性 → 自动化”里打开。Windows 只让你自己改默认应用，HXBot 打开“默认应用”页，助手在那里一步步点。一条路走不通，助手自动换下一条（直达 → 命令 → 控件 → 看图），并写明走的是哪条。
  • 打开应用后一步步操作：跟助手说在哪个应用里做什么，例如“在备忘录里新建一条，写上明天上午 10 点的会”。助手先在对话里列出步骤（一张进度卡），再用鼠标和键盘一步步做：点按钮、输入文字、按快捷键、滚动、拖动、点菜单。每一步都核对界面有没有按预期变化，做不下去就停下来说明卡在哪里，或者换一种做法。能在后台点的就不抢你的鼠标。发送、付款、购买、删除、发布之前，先在对话里问你。随时按 ⌃⌥Esc（Windows：Ctrl+Alt+Esc），助手在这台电脑上的操作马上停下（v1.7.0 起这组键只在助手操作电脑时占用，平时还给其他应用）。
  • 不打扰其他应用（v1.7.0 起）：助手输入文字、按快捷键之前先看最前面的是不是它在操作的应用；你切到了别的应用，它就不发按键，也不把窗口拉回前面，而是停下来请你回去后再说。一次操作结束时松开所有修饰键，剪贴板保持你原来复制的内容。高亮框每秒最多读两次窗口，助手的进程和它运行的命令以低于正常的优先级运行，读大应用的窗口有上限，别的应用不会被拖慢或卡住。更新下载限速 2 MB/s，远程桌面最多 10 Mbit/s；Windows 上停下助手时，它打开的有窗口的应用留下。
  • 直接打开和直接修改：开了 Computer Use 的助手可以按名称直接打开这台电脑上的应用、系统设置的某一页、文件夹、文档和网址，也可以直接修改深色模式、程序坞、任务栏等常用设置，不用截图和点鼠标。例如“打开蓝牙设置”“把深色模式打开”；中文名也可以用拼音说，例如“wangyiyun”。隐私与安全、密码这类页面，助手只打开，由你自己修改；第一次修改外观或程序坞时，macOS 会问一次是否允许 HXBot 控制“系统事件”。Windows 的屏幕亮度要先在“设置 → Computer Use → 这台电脑上的应用和设置”中运行一次自检（不会改变任何设置的值），通过后助手才直接修改；在那之前助手会打开设置页去改。在同一处还可以重新建立目录（新装的应用找不到时用）。
  • 限制：HXBot 只能从命令本身看出要修改、删除哪些文件；助手写的脚本或程序自己去改、去删的文件看不出来，用变量写的位置也只能按“看不出来”处理。在 Mac 上用 Cursor、Kimi、DeepSeek 等服务商时，助手自己的命令被系统限制在工作区等文件夹里，不能在外面新建文件（Homebrew、npm、pip 等装软件的文件夹除外）；装应用、截屏、控制别的应用和运行 AppleScript 由 HXBot 来做。OpenCode 每一步都先问 HXBot，v1.6.8 起不受这个限制。处理重要资料时，请先备份，并把资料和助手的工作区分开存放。

用好助手的几条建议：

  • 一个助手一个职责，职责写得越具体，结果越稳定。
  • 对重要的输出和不可逆的操作（删除文件、发送邮件、付款）先核实再执行。
  • 网页、邮件和文件中可能藏有诱导助手执行恶意操作的内容（提示注入），不要让助手处理来源不明的内容。确认卡片上看不懂原因时选择拒绝，“始终允许”只给你确实放心的文件夹和命令。
  • 不要让助手处理涉密信息、他人的敏感个人信息或生产系统。

助手头像：每个助手的头像是 30 种小动物之一（长颈鹿、小犀牛、小猪、小马、小象、小鱼等），和 HXBot 的长颈鹿标志同一画风。在助手设置里点头像右下角的笔，可以在“动物”“更多动物”里换一只，在颜色里换颜色，也可以上传自己的图片。

6. 服务端：发布服务器与邀请成员#

“服务器”就是运行 HXBot 桌面端的那台电脑。发布服务器后，你可以从网页版和手机上使用它，也可以邀请同事一起使用其中的助手。服务器所在的电脑需要开机、联网并运行桌面端，别人才能连接。

6.1 发布服务器#

  1. 在 Mac 或 Windows 上打开桌面端，用邮箱和密码登录。
  2. 在左侧服务器栏右键当前服务器（或点“…”），选“服务器设置”，打开“成员”。
  3. 打开“发布该服务器”。显示“可在公网访问，仅受邀者可以登录。”即表示发布成功。

发布后，你自己可以立即在网页版和手机上看到这台服务器；其他人需要你的邀请才能加入。

6.2 邀请成员#

  1. 在“服务器设置 → 成员”中点“邀请成员”。
  2. “邀请方式”选择：
    • “邀请链接”：一次性链接，24 小时后过期，用过一次即失效；
    • “永久链接”：不会过期，可多次使用，任何拿到它的人都能加入，只发给你信任的人。
  3. “邀请角色”选择“成员”或“管理员”。
  4. 点“创建链接”，再点“复制链接”，通过你自己的渠道发给对方；对方用手机时，也可以点“显示邀请二维码”让对方扫码。

请优先使用“邀请链接”或“永久链接”；“邮箱”方式在研究版中可能不可用。

每个邀请链接都不同，形如 https://bot.hxallai.com/join?api=…&server=…&fingerprint=…&invite=…，里面带着服务器的编号、身份指纹和一次性凭证，所以无法提前给出一个通用链接。不再需要的邀请可以在“待处理的邀请”中撤销。

6.3 角色与权限#

角色可以做什么
所有者运行服务器的人。可以发布或停止发布服务器、邀请和移除成员、调整角色和权限，并使用所有助手
管理员协助管理成员和邀请，可以使用所有助手
成员按“角色”设置使用允许的助手
  • 在“服务器设置 → 角色”中选择成员可以使用哪些助手。成员拥有“所有人”和自己所属角色中最高的访问权限；所有者和管理员可以使用所有助手。
  • 在“成员”列表中可以“设为管理员”“设为成员”或“移除成员”。被移除的成员会失去对该服务器及其共享对话的访问权限。
  • “审计日志”记录成员、角色和助手访问权限的变更，最新的在前，主机保留最近 500 条。
  • 同一服务器的成员可以互相看到邮箱、显示名称和头像。成员的对话和发送的文件保存在所有者的电脑上，所有者和管理员可能看到它们。

6.4 加入别人的服务器#

  1. 先在 https://bot.hxallai.com 登录（还没有账号请先点“创建账号”）。
  2. 选择一种方式打开邀请：
    • 网页版：打开 https://bot.hxallai.com/app ，点“用邀请加入”；
    • 桌面端、安卓端或 iOS 端：点服务器栏的“添加服务器”；
    • 也可以直接在浏览器里打开收到的邀请链接，页面会引导你在 HXBot 中打开它；手机上可以“扫描邀请二维码”。
  3. 粘贴链接，点“查看邀请”。确认页面显示这是一份已验证的邀请，核对服务器名称、访问权限和过期时间后，点“连接”。

发到指定邮箱的邀请只对该邮箱有效，请用对应的邮箱登录。想退出时，在服务器栏右键该服务器，选“离开服务器”。

6.5 网页版#

网页版地址是 https://bot.hxallai.com/app ，会列出你发布或加入的服务器。建议使用最新版的 Chrome、Edge、Safari 或 Firefox，手机浏览器也可以使用。网页版通过加密连接直接访问服务器所在的电脑，不在浏览器中保存对话内容；服务器所在的电脑关机或桌面端未运行时，网页版无法使用该服务器。

7. 在手机上使用#

安装：Android 用户在手机浏览器中打开 https://bot.hxallai.com ，登录后下载 APK 安装；iPhone、iPad 用户用 Safari 打开同一地址，登录后点 iPhone / iPad 卡片上的按钮安装（TestFlight 或直接安装，见第 3 节）。

登录：两种方式任选其一。

  • 在手机上直接用邮箱和密码登录；
  • 用桌面端扫码登录：在桌面端打开“设置 → 手机连接”，点“添加手机”，选“已安装，登录”；在手机上打开 HXBot，点“扫描二维码”，把相机对准电脑屏幕。手机还没装应用时选“未安装，获取应用”，扫码打开下载页。

使用：手机会列出你的服务器，可以查看助手的进度、继续对话、语音输入，也可以从其他应用“分享”文字、图片和文件给 HXBot。手机端会在本机加密缓存它显示过的内容，退出登录时删除。

管理手机：在桌面端“设置 → 手机连接 → 你的手机”中查看已登录的手机；在手机端“设置 → 已登录设备”中管理登录。

退出登录：点账号菜单中的“退出登录”。

注销账号：在“设置 → 个人资料”最下面点“注销账号…”，输入密码确认（没有设置过密码的账号，例如只用第三方登录的，改用这个账号的邮箱确认）。账号立即删除、不能恢复：注册资料、绑定的第三方账号、所有设备上的登录、加入的服务器和你发布的服务器都会删除，同一个邮箱和手机号码以后可以重新注册；你电脑上的助手、对话和文件不受影响。手机端在“设置 → 个人资料 → 注销账号”，网页版同样在“设置 → 个人资料”。也可以用账号邮箱发邮件到 bot@hxallai.com 申请，我们核验后在 15 个工作日内处理。

保密箱：密码、API 密钥、令牌，以及网站和应用的登录信息，请存进保密箱（桌面端：服务器设置 → 保密箱；手机端：服务器设置里的“保密箱”）。助手使用这些机密时只拿到文件路径，或由 HXBot 替它自动填写，AI 模型看不到明文。请不要在聊天里发送密码：聊天框发现消息里像有密码或密钥时，会先拦下提醒，你可以点“打开保密箱”改存，或点“仍然发送”。助手需要密码或密钥时，也会弹出保密表单让你填写。

11. 常见问题#

登录时提示“该邮箱不在研究版名单中”？研究版只对名单内的邮箱开放。请发邮件到 bot@hxallai.com 申请开通。

提示“尝试太频繁”或“密码输错次数太多”？为防止暴力破解，登录有频率限制。请等约 15 分钟后重试，并确认密码输入正确（注意大小写和全角、半角）。忘记密码时，在门户登录框下方点“忘记了密码？”。

收不到邮箱验证码或短信验证码？先看垃圾邮件箱，确认邮箱和手机号没有写错；验证码 10 分钟内有效，60 秒后可以重新获取。同一个手机号每天最多获取 10 次。短信验证码只支持中国大陆手机号。仍然收不到时，请发邮件到 bot@hxallai.com。

提示“这个邮箱已经注册”“这个手机号已经注册了账号”或“这个用户名已经有人用了”？一个邮箱、一个手机号码都只能注册一个账号，请用已有的账号登录，忘记了密码就点“忘记了密码？”；用户名不能与别人重复，换一个即可。

网页版或手机上看不到我的服务器？请确认：服务器所在的电脑已开机、联网，桌面端正在运行；服务器已经发布（第 6.1 节）；你在各端登录的是同一个账号。

一直显示“正在连接”或“连接失败”？可能是网络限制了点对点连接。HXBot 会自动改用中继；公司或学校网络如果拦截了中继端口，请让网络管理员放行到 turn.bot.hxallai.com 的 UDP / TCP 3478 和 TCP 5349 端口。也可以换一个网络，或重启桌面端后再试。

邀请链接打不开或提示过期？一次性邀请 24 小时后过期，并且只能用一次；发到指定邮箱的邀请只对该邮箱有效。请让服务器所有者创建新的链接。

打开某个地址显示“找不到页面”？链接可能已失效或输错。请回到 https://bot.hxallai.com 重新进入。

助手调用模型失败？请在“服务器设置 → 服务商”中检查服务商的登录状态、密钥、额度和地区限制；免费模型的可用性由其提供方决定，失败时可以换一个服务商。

如何更新到新版本？客户端会自动更新：桌面端自动下载，在弹出的窗口里点“立即更新”即可；手机端自动打开新版本，你点“安装”即可，见第 3 节“更新”。

提示“这个版本的 HXBot 太旧了”，登录不了？这一版起旧版本不能再登录。请用浏览器打开 https://bot.hxallai.com 登录，下载新版本安装后再登录。

升级后要求重新登录？升级到这一版时，所有设备的登录都会失效一次，用邮箱和密码重新登录即可，助手和对话都在。

Mac 上弹出“HXBot 想要使用你储存在钥匙串的‘HXBot Safe Storage’中的机密信息”？这是旧版本的问题，新版本已经不再使用钥匙串：登录状态、API 密钥等机密都保存在 HXBot 自己的加密保密箱里（数据文件夹中，只有你的 Mac 账户能读），启动和升级都不会再弹这个框。从旧版本升级后，请重新登录一次，并把之前保存的 API 密钥再填一次；之后一直有效。钥匙串里旧的“HXBot Safe Storage”项目可以在“钥匙串访问”里删除，也可以不管。

换电脑后数据会同步吗？不会。助手、对话和文件保存在原来那台电脑上。你可以继续把原来的电脑作为服务器发布，从新电脑“添加服务器”连接它。

可以用于商业项目吗？不可以。研究版仅限非商业研究使用。
