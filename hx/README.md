# HXBot 研究版

弘犀智能基于开源项目改造的非商业研究版多智能体工作台（源码来源与许可见仓库根目录的 LICENSE、NOTICE）。账号、信令、中继服务全部部署在弘犀自有的阿里云服务器上。用户在 https://bot.hxallai.com 注册账号（邮箱 + 自己的密码，注册时验证邮箱和手机号码，也可以用微信、支付宝等第三方账号登录），登录后下载客户端，或直接使用网页版。

> 遵循 PolyForm Noncommercial License 1.0.0，仅限非商业研究用途。详见 docs/许可与合规.md。

## 组成

```
                    https://bot.hxallai.com（门户：注册、登录、下载、网页版）
                                   │
 ┌──────────── 阿里云 ECS（与官网同一台，共用 nginx）────────────┐
 │ nginx ── bot / api.bot ──► 账号服务（workerd，127.0.0.1:8787） │
 │       └─ signal.bot ────► 信令服务（127.0.0.1:8081）           │
 │ 中继服务 coturn：3478/udp+tcp、5349/tcp、49152-65535/udp       │
 └───────────────────────────────────────────────────────────────┘
        ▲ 注册登录、发现主机、建立连接            ▲ 无法直连时转发加密数据
        │                                     │
 桌面端（Mac / Windows，智能体运行在这里） ◄══ 点对点加密 ══► 网页版 / 安卓端
```

| 部分 | 状态 |
| --- | --- |
| 门户（注册登录 + 下载中心） | ✅ |
| 网页版 /app | ✅ |
| Mac（Apple 芯片）桌面端 | ✅ 需在 Mac 上构建 |
| Windows 桌面端 | ✅ 需在 Windows 或 GitHub Actions 上构建 |
| Android | ✅ 需在装有 Android Studio 的电脑或 GitHub Actions 上构建 |
| iOS | ✅ 需在装有 Xcode 的 Mac 上构建；TestFlight 邀请链接或 Ad Hoc 安装包发布到下载中心 |
| 官网入口 | 见 website/ 目录 |

## 上线顺序

1. 按部署文档完成服务器部署，check.sh 全部通过。
2. 按客户端构建文档构建安装包，上传到下载中心。
3. 自己完整走一遍：门户注册并登录 → 下载安装 Mac 端 → 发布服务器 → 网页版和安卓端连接。
4. 确认许可问题（建议邮件联系原作者）后，再在官网加入口。
